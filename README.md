# Valorant Tracker: releases

Installers and automatic updates for Valorant Tracker, a VALORANT stats app for Windows: your profile and match history, the full match report, trends, agents, maps and weapons, a live view of every match with each player's rank and recent form, and in-game overlays. It runs in the tray, without Overwolf.

## Download

Get `Valorant-Tracker_x.y.z_x64-setup.exe` from the [latest release](https://github.com/Niiihuel/valorant-tracker-releases/releases/latest) and run it. It installs for your Windows user, no admin needed.

The app keeps itself up to date: it looks for a new version when it starts and every 6 hours, and installs it when you click "Update now" (Settings › General also has "Check for updates"). Updates are signed, so the app only installs builds from this project.

## Requirements

- Windows 10 or 11.
- The Riot Client open and signed in, and VALORANT opened at least once on the PC.
- For the in-game overlays, VALORANT's Display Mode set to Windowed Fullscreen.

## Descarga (español)

Bajá `Valorant-Tracker_x.y.z_x64-setup.exe` de la [última versión](https://github.com/Niiihuel/valorant-tracker-releases/releases/latest) y ejecutalo: se instala para tu usuario, sin permisos de administrador. La app se actualiza sola (busca versiones nuevas al iniciar y cada 6 horas). Necesitás el Riot Client abierto con tu sesión, y para los overlays, VALORANT en Pantalla completa en ventana.
